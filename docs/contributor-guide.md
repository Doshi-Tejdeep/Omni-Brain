# Contributor Guide

## Before You Start

- Pull the latest changes from the `main` branch.
- Create a new feature branch for your work.
- Install all project dependencies.

## Development Workflow

1. Create a feature branch.
2. Make focused changes.
3. Run formatting and linting tools.
4. Run all tests locally.
5. Commit using meaningful commit messages.
6. Push your branch and open a Pull Request.

## Code Quality

Before submitting a Pull Request, ensure:

- All tests pass.
- Pre-commit hooks complete successfully.
- Code follows the project's coding standards.
- Documentation is updated if required.

## Pull Requests

A good Pull Request should:

- Have a clear title.
- Include a short summary of the changes.
- Reference related issues when applicable.
- Be limited to a single logical change.

## Reporting Issues

When creating an issue:

- Describe the problem clearly.
- Include reproduction steps.
- Mention your operating system and Python version if relevant.
